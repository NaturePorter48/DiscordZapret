Сначала активируйте безопасный DNS (Secure DNS)\n    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщик по умолчанию"\n    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` — Cloudflare может быть заблокирован\n    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется\n    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно\n\n2. Перейдите на [страницу последнего релиза](https://github.com/NaturePorter48/zapret-discord-youtube/releases/latest) и скачайте архив zip/rar\n\n3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять\n\n4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов\n\n5. Запустите подходящий файл\n    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`\n    * Чтобы добавить стратегию в автозагрузку, выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*\n\n## ℹ️Кратко о файлах\n\n- [**`general.bat ...`**](./general.bat) — ручной запуск выбранной стратегии\n\n  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты — ALT, FAKE и другие — пока не найдёте подходящий для себя**\n\n- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:\n  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>\n  - **`Remove Services`** — удаление стратегии и WinDivert из списка служб\n  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert\n  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  \n  **После изменения параметра стратегию необходимо перезапустить.**  \n  Текущее состояние показывается в скобках: включено или выключено.\n  - **`IPSet Filter`** — управление обходом сервисов, перечисленных в `ipset-all.txt`.  \n  Параметр полезен при проверке ресурса, который без zapret работает, а с ним — нет  \n  В скобках отображается состояние:\n    - `none` — IP-адреса не проходят проверку\n    - `loaded` — проверяется принадлежность IP списку\n    - `any` — под фильтр попадает любой IP  \n  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений\n  - **`Replace active fakes`** — замена текущего фейка на другой файл из каталога `bin`\n  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория\n  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>\n  - **`Check for Updates`** — ручная проверка наличия обновлений\n  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  \n  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы приложения\n  - **`Run Tests`** — проверка стратегий:\n    - `Standard tests` — тестирование сайтов из `utils/targets.txt`\n    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon\n\n\n## ☑️Частые вопросы и неисправности\n\n### После запуска `general*` ничего не видно\n\n- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  \nЕсли процесс не появился, обратитесь к [#522](https://github.com/NaturePorter48/zapret-discord-youtube/issues/522)\n\n### Не подходит ни одна стратегия\n- Откройте командную строку с правами администратора\n- Выполните по очереди следующие команды:\n\n    `netsh winsock reset`\n  \n    `netsh int ip reset all`\n  \n    `netsh winhttp reset proxy`\n  \n    `ipconfig /flushdns`\n  \n- Перезагрузите компьютер\n\n### Не открывается Telegram в браузере\nЗапустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  \n  - Скопируйте всё содержимое открывшегося блокнота\n  - С правами администратора откройте текстовый редактором файл `hosts` в созданной папке\n  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки\n  - Сохраните файл и проверьте соединение ещё раз. Если проблема осталась, убедитесь, что изменения действительно записались.\n\n#### Результат не гарантирован. При отсутствии эффекта используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/NaturePorter48/tg-ws-proxy) либо с любым публичным прокси.\n\n### Обход не запускается или снова перестал работать\n\n> [!IMPORTANT]\n> **Стратегии не обязательно работают постоянно.**\n> После обнаружения конкретная стратегия может перестать работать, даже если раньше какое-то время справлялась.\n> В репозитории есть много вариантов обхода. Если готовые стратегии не помогают, создайте новую на основе одной из них, изменив параметры.\n> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).\n\n- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`\n\n- Убедитесь, что нужный адрес присутствует в доменных или IP-списках\n\n- Переберите другие стратегии, например **`ALT`** и **`FAKE`**\n\n- Выполните полную переустановку по инструкции ниже\n\n- Дополнительная информация есть в [#765](https://github.com/NaturePorter48/zapret-discord-youtube/issues/765)\n\n### Как полностью обновить или переустановить проект?\n- Сохраните добавленные вами ресурсы и данные\n- Перезагрузите устройство\n- Откройте `service.bat` -> `Remove Services`\n- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y\n- Удалите старый каталог zapret\n- Скачайте свежую версию `zapret-discord-youtube-...` [со страницы релизов](https://github.com/NaturePorter48/zapret-discord-youtube/releases)\n- Нажмите ПКМ по архиву и откройте свойства. Если в правом нижнем углу есть пункт разблокировки, отметьте его, нажмите применить и подтвердите\n- Распакуйте архив в новый каталог в корне диска, используя путь без пробелов и специальных символов\n- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если выбранная стратегия не работает, закройте программу через значок замка на панели задач и попробуйте следующую\n- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` -> выбранная стратегия\n\n### Игра или приложение не работает при включённом zapret\n\n- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.\n\n### Античит обнаруживает WinDivert\n\n- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide\n\n### На Windows 7 требуется цифровая подпись драйвера WinDivert\n\n- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)\n\n### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб\n\n1. Определите имя службы командой в командной строке Windows, открытой через Win+R и `cmd`:\n\n```cmd\ndriverquery | find "Divert"\n```\n\n2. Остановите службу и удалите её следующими командами:\n\n```cmd\nsc stop название_из_первого_шага\n\nsc delete название_из_первого_шага\n```\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube\n\n- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен\n- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться\n- Если прежняя стратегия больше не помогает, проверьте остальные\n- Дополнительные сведения: [#251](https://github.com/NaturePorter48/zapret-discord-youtube/discussions/251)\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord\n\n- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён\n- Сначала определите стратегию, на которой открывается YouTube, и запустите её\n- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord\n- Проверьте, изменилось ли поведение приложения после очистки кэша\n- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей\n- Если Discord не открывается и в браузере, снова последовательно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах\n- См. также [#252](https://github.com/NaturePorter48/zapret-discord-youtube/discussions/252)\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram\n\n- Попробуйте [tg-ws-proxy](https://github.com/NaturePorter48/tg-ws-proxy)\n- Либо воспользуйтесь бесплатными MTProto-прокси, доступными в интернете\n\n### Игры не подключаются\n\nИгры используют разные сетевые схемы, поэтому проверить и исправить каждую из них невозможно.\n\nОбычно стоит сделать следующее:\n- через `service.bat` обновить ipset и включить `Game Filter`\n- если результата нет, дополнительно активировать `ipset any`\n\nУчитывайте, что режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`\n\nЕсли это также не помогло, создайте обсуждение в разделе [Discussions](https://github.com/NaturePorter48/zapret-discord-youtube/discussions), а не issue, и дождитесь ответа других игроков.\n\n### Нужной проблемы нет в списке\n\n- Опишите её [здесь](https://github.com/NaturePorter48/zapret-discord-youtube/issues)\n\n## 🗒️Добавление адресов других ресурсов\n\nРасширить список адресов для обхода можно через следующие файлы:\n- **`list-general-user.txt`** — домены; поддомены будут учтены автоматически\n- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется\n- **`ipset-all.txt`** — IP-адреса и подсети\n- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить\n  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`\n\n## ⭐Поддержка проекта\n\nПоддержать проект можно, поставив этому репозиторию :star: в правом верхнем углу страницы\n\nМатериально поддержать разработчика оригинального zapret можно [здесь](https://github.com/bol-van/zapret?tab=readme-ov-file#%D0%BF%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%B0%D1%82%D1%8C-%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D0%B0)\n\n## ⚖️Лицензирование\n\nПроект распространяется по лицензии [MIT](https://github.com/NaturePorter48/zapret-discord-youtube/blob/main/LICENSE.txt)\n\n## 🩷Благодарность участникам проекта\n\n[![Contributors](https://contrib.rocks/image?repo=NaturePorter48/zapret-discord-youtube)](https://github.com/NaturePorter48/zapret-discord-youtube/graphs/contributors)\n\n💖 Спасибо разработчику [zapret](https://github.com/bol-van/zapret) — [bol-van](https://github.com/bol-van)
